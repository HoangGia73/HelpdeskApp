# End-User License Agreement template

This is a publisher-completion template and is not legal advice. Replace every
`[PUBLISHER]` field and obtain counsel approval before commercial distribution.

## License grant

[PUBLISHER] grants the customer a limited, non-exclusive, non-transferable right
to install and use IT Support Tool Suite for the number of devices and users in
the order form. Ownership and intellectual-property rights remain with
[PUBLISHER].

## Restrictions

The customer may not redistribute, resell, reverse engineer, bypass licensing,
or use the software to access systems or data without authorization.

## Administrative operations

The software can modify network configuration, install drivers and printers,
install or uninstall software, and restore files. The customer is responsible
for authorization, tested backups, change control, and reviewing confirmation
screens before privileged operations.

## Warranty, liability, termination and governing law

These clauses must be completed in the signed commercial agreement, including
warranty period, liability cap, exclusions, termination rights, governing law,
and dispute venue.
