# Support runbook

Ask the customer for application version, Windows version, operation attempted,
timestamp, sanitized screenshot, and the relevant section of
`%LOCALAPPDATA%\ITSupportToolSuite\logs\application.log`.

Never request a backup password, private key, complete browser profile, Outlook
mailbox, or unredacted customer backup. Before escalation, reproduce on a test
machine and record whether UAC was accepted and whether endpoint protection
blocked the signed executable.
